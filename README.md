# 商品企画書 / 原価表 Web アプリ

Google スプレッドシートの「商品企画書」と「原価表」を Web アプリ化したものです。
ログイン・商品ごとの保存・Excel / PDF 出力・画像追加・Excel と同じ自動計算に対応し、
さまざまな商品開発に再利用できます。

## 主な機能

- **ログイン / 新規登録** … Supabase 認証（メール + パスワード）。招待コードで登録を制限。
- **商品ごとの保存** … クラウド（Supabase）に保存。一覧から開く・複製・削除。自動保存付き。
- **自動計算（原価表）** … セット原価・粗利額・粗利率・原価率・総発注金額・金型償却込原価・
  損益分岐原価・粗利率目標差などを入力に応じてリアルタイム計算（元の Excel 数式を忠実に再現）。
- **商品企画書** … 商品名 / 訴求点 / ヘッドコピー / 商品説明 / 仕様 / 価格（原価表から自動連動）/
  バーコード・JAN / サイズ・梱包・重量 / 試験情報 / 別売品 などを編集。
- **画像追加** … 商品画像・詳細画像をドラッグ不要のクリックでアップロード（Supabase Storage）。
- **Excel 出力** … `.xlsx`。原価表シートは**生きた数式付き**で書き出し（開いて再計算可能）。
- **PDF 出力** … 企画書 + 原価表を A4 レイアウトで 1 つの PDF に出力。

## 技術構成

| レイヤ | 採用技術 |
| --- | --- |
| フロント | Vite + React + TypeScript（SPA） |
| 認証 / DB / 画像 | Supabase（Auth / Postgres + RLS / Storage） |
| 登録 | Supabase Edge Function `m3-register`（招待コードで自動確認ユーザー作成） |
| Excel | ExcelJS | 
| PDF | jsPDF + html2canvas |
| ホスティング | Vercel（静的配信） |

## 計算ロジック（原価表）

```
セット原価(行)   = 数量/セット × 単価
発注金額(行)     = 単価 × 発注数
セット原価(合計) = Σ セット原価(行)
粗利額           = 売価 − セット原価
粗利率           = 粗利額 / 売価
原価率           = セット原価 / 売価
金型償却/セット  = 金型総額 / セット総数
金型償却込原価   = セット原価 + 金型償却/セット
損益分岐原価     = 売価 × (1 − 粗利率目標)
粗利率目標差     = 粗利率 − 粗利率目標
売価(税込)       = 売価 × (1 + 消費税率)
粗利額(税込)     = 粗利額 × (1 + 消費税率)
掛け率           = 粗利額 / 売価（提供テンプレートの定義に準拠）
```

## ローカル開発

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 本番ビルド（dist/）
```

### 環境変数（任意）

`.env` に設定可能。未設定でも既定値（公開可能な anon キー）で動作します。

```
VITE_SUPABASE_URL=...
VITE_SUPABASE_ANON_KEY=...
VITE_INVITE_CODE=        # 登録画面の招待コード初期値（任意）
```

## ログイン情報

- 既存アカウント（例: `h0301m@gmail.com`）は、これまでお使いのパスワードでそのままログインできます。
- 新規メンバーは **新規登録** から、招待コード **`SHOWA2026`** で登録してください。
- 招待コードは Supabase Edge Function のシークレット `M3_INVITE_CODE` で変更できます。

## デプロイ

Vercel に接続して `main`（または対象ブランチ）をビルドするだけで公開できます
（`vercel.json` に SPA フォールバック設定済み）。
