# 商品企画書システム（M3_genka）

昭和商会の「商品企画書」をそのままの体裁で Web 上で編集できるアプリです。
画像の配置、**原価率の自動計算**、**PDF / Excel への書き出し**、**保存**、**ログイン**機能を備えています。

元の Google スプレッドシート（企画書・原価表・シミュレーション・マスタ）を再現し、
原価表の入力から企画書の価格欄（目標売価・粗利・掛け率など）が自動連動します。

---

## 主な機能

| 機能 | 内容 |
| --- | --- |
| 企画書エディタ | 元書式（濃緑タイトル・緑帯セクション・価格欄など）を保ったまま、各項目をその場で編集 |
| 画像配置 | 「＋ 画像を追加」でアップロードし、ドラッグで移動・右下ハンドルでサイズ変更 |
| 原価率の自動計算 | セット原価・粗利額・粗利率・**原価率**・金型償却込原価・損益分岐原価・総発注金額などを自動算出 |
| 価格欄の自動連動 | 原価表の入力から、企画書の目標売価（税別/税込）・粗利額（税別/税込）・掛け率・MOQ を自動反映 |
| PDF 書き出し | 企画書の見た目そのままを A4 PDF としてダウンロード |
| Excel 書き出し | 「原価表」「企画書」2 シートの `.xlsx` をダウンロード |
| 保存 | ユーザーごとにサーバー保存（自動保存＋手動保存）。複数の企画書を管理 |
| ログイン | ユーザー登録 / ログイン（パスワードは bcrypt でハッシュ化）・パスワード変更 |
| 印刷 | ブラウザの印刷機能（高品質 PDF 出力にも利用可） |

計算式は元の原価表と一致することを検証済みです（`npm test`）。

---

## 動作環境

- Node.js 18 以上

## セットアップ

```bash
npm install        # 依存関係をインストール（PDF/Excel ライブラリ含む）
npm start          # サーバー起動
```

起動後、ブラウザで <http://localhost:3000> を開きます。

初回起動時に初期ユーザーが自動作成されます。

```
ユーザー名: admin
パスワード: admin1234
```

> ⚠️ 運用前に必ずパスワードを変更してください（画面右上「パスワード変更」）。
> 新しいアカウントはログイン画面の「新規登録」から作成できます。

### 環境変数（任意）

| 変数 | 既定 | 説明 |
| --- | --- | --- |
| `PORT` | `3000` | 待ち受けポート |
| `SESSION_SECRET` | 起動毎に自動生成 | セッション署名鍵。固定するとサーバー再起動後もログインが維持される |
| `COOKIE_SECURE` | `0` | `1` で HTTPS 環境向けに Secure クッキーを有効化 |

## 使い方

1. **ログイン** 後、左側に保存済みの企画書一覧、中央に企画書が表示されます。
2. 上部タブで **「企画書」** と **「原価表」** を切り替えます。
3. **原価表** の黄色セル（セット総数・売価・金型総額・目標粗利率・税率、各行の数量/単価/発注数）を編集すると、
   原価・粗利・原価率・発注金額・企画書の価格欄が即座に再計算されます。
4. **企画書** の各項目は直接クリックして編集できます。商品画像は「＋ 画像を追加」で配置し、ドラッグで移動・サイズ変更します。
5. 右上の **「保存」** でサーバーに保存（編集中は約 2 秒後に自動保存）。
6. **「PDF書き出し」「Excel書き出し」** でダウンロードします。

## データの保存場所

- すべてのデータは `data/db.json`（単一 JSON ファイル）に保存されます。外部 DB は不要です。
- 画像は企画書データ内に埋め込まれて保存されるため、PDF/Excel 書き出しやバックアップが容易です。
- バックアップは `data/db.json` をコピーするだけです（`.gitignore` 済み）。

## 構成

```
server.js                 Express サーバー（認証・保存 API・静的配信）
public/
  index.html              画面（ログイン / エディタ）
  css/style.css           企画書の体裁を再現したスタイル
  js/
    assets.js             ロゴ（インライン SVG）
    calc.js               原価計算エンジン
    defaults.js           新規企画書の初期データ（27SS サンプル）
    sheet.js              企画書・原価表の描画とデータバインド
    export.js             PDF / Excel 書き出し
    api.js                サーバー API ラッパー
    app.js                アプリ全体の制御
tests/calc.test.js        原価計算の検証テスト
```

## 補足

- PDF/Excel 用ライブラリ（jsPDF / html2canvas / SheetJS）は `npm install` で取得され、
  サーバーから `/vendor/...` 配信されます（CDN 不要・オフラインでも動作）。
- ロゴはインライン SVG（`public/js/assets.js`）で、商品画像はユーザーがアップロードして配置します。
  アップロード画像は企画書データに埋め込まれて保存され、PDF/Excel 書き出しやバックアップが容易です。
- 日本語フォントはインストール済みであれば Noto Sans JP を使用し、無い場合はシステムのゴシック体にフォールバックします。
- 本アプリのログインは社内・LAN 利用を想定しています。インターネット公開時は HTTPS 化（`COOKIE_SECURE=1`）と
  `SESSION_SECRET` の固定を推奨します。
